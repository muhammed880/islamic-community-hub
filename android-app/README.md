# Android app scaffold

This folder will contain the Android Kotlin + Jetpack Compose project. To connect it to Firebase:

1. Create an Android app in your Firebase project with package name `com.nikahnaama.app` (or change below to your preferred package).
2. Download `google-services.json` and place it in `android-app/app/`.
3. Create the Android project locally (Android Studio) or let me push an initial project skeleton on request.

If you want me to push the Android project files now, reply: "Push Android scaffold" and I will add the initial app source files.
